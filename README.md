# Operation Safe Return

A playable Expo recreation of the paper-and-ink hostage rescue. Find the detention building, unlock the hostage, and escort him to the jeep at the east gate. Guards patrol the yard and will shoot if they see you.

This is an independent mobile version, written from scratch for Expo. It is inspired by [Operation Safe Return](https://github.com/byteab/operation-ink) by Ehsan Sarshar ([@byteab](https://github.com/byteab)). The live browser demo of the original is at [operation-ink.vercel.app](https://operation-ink.vercel.app).

## Run

```sh
npm install
npx expo start
```

Open the project in Expo Go (iOS or Android), a development build, or the web:

```sh
npx expo start --web
```

Landscape is preferred. The mission also fits a portrait phone.

`npm test` runs the mission logic checks (route, combat, death, retry). `npm run typecheck` runs TypeScript.

## Controls

- Left stick: move. Hold Sprint to run.
- Drag the right side of the screen: look.
- Fire: semi-automatic pistol. Reload fills the magazine from reserve.
- Use: unlock the cell, open the gate, take the field dressing, board the jeep.
- Pause: volume, reduced motion, restart.

On the web, WASD or the arrow keys move, dragging the right side looks, F or E uses, R reloads, Space fires, and Esc pauses.

## Stack

Expo SDK 57, React Native, and TypeScript. The world is drawn with **Three.js r166** through **expo-gl**, using **expo-three**'s `Renderer` so the same scene runs in Expo Go and on the web. Materials are unlit (`MeshBasicMaterial`) on white paper, with black edge strokes. Touch controls are plain React Native views over the GL surface. `expo-audio` plays the cues.

## Audio licence

Every sound in `assets/sfx/` is **original procedural synthesis** generated by `scripts/generate-sfx.mjs`. The cues are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

**No Project I.G.I. audio, and no other game recordings, are included.**

Regenerate them with `node scripts/generate-sfx.mjs`.

## What this version ships

- Title, begin, pause, death, and mission-complete screens
- A short compound: yard, mess hall, detention annex, underground cell, exit gate, and jeep
- One pistol, three guards, a heal pickup, and an alarm you can silence
- Hostage follow, with a short assist if he snags on a doorway
